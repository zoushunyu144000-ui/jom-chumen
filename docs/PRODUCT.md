# 产品需求

> 其他 Agent：改功能前先读这一页。和这里打架的 PR 不要合。

## 目标

做一个给 **东南亚华人青年** 用的出门局产品。场景：飞盘、摄影、徒步、读书会、citywalk、浆板、球类、露营、深聊、瑜伽。

第一批城市：槟城、吉隆坡、新山、新加坡、曼谷。城市选择器已经能搜全世界，但活动表仍是这五个枚举。

对标：粗门小程序的「发现局 / 报名 / 俱乐部」，不是票务电商。

## 角色

| 角色 | 做什么 |
| --- | --- |
| 访客 | 逛发现、看活动、查报名号（手机号或 HD- 号） |
| 登录用户 | 改资料、票夹、我的申请、发消息 |
| 主办人 | 建俱乐部、发活动、上传收款码、审报名 |
| 平台管理员 | **还没有**。现在每个主办人只审自己发的局 |

## 报名规则（硬约束）

1. 点「提交申请」**不等于**报名成功。
2. 状态机：`pending` → `approved`（成功） / `rejected` / `cancelled`。旧数据里的 `paid` 视同 `approved`。
3. 用户自己付款：微信、支付宝、TNG、现金。页面展示主办人收款码 + WhatsApp 客服码。
4. 主办人核验后点「同意」，票才进票夹。
5. 同一手机号 + 同一活动，在 pending / approved 期间不能重复申请。
6. 报名号格式：`HD-YYYYMMDD-NNN`（吉隆坡时区日期）。
7. 免费局 `price = 0`，支付方式记为 `free`，仍走 pending 审核。

## 信息架构

底部五栏：**发现 / 俱乐部 / 发布 / 消息 / 我的**

- 发现：逛局
- 俱乐部：主办工作台（审报名、改活动、改俱乐部）。不是公开俱乐部列表
- 发布：大加号，发起活动
- 消息：站内信
- 我的：资料、票夹、我的申请、查询报名

公开俱乐部列表在 `/clubs`。工作室在 `/club`。这两个路径不要合并，导航高亮不要用 `startsWith("/club")`（会误伤 `/clubs`）。

## 视觉

纸色底 `#f4f3ee` + 墨色字 + 柠檬绿 `#c6e14a`。中文为主。时间按 24 小时、吉隆坡时区。不要 emoji 当图标，不要紫渐变。

## 明确不做

- 支付网关、银行卡自动扣款、点一下就出票
- 微信登录（没有开放平台）
- 把「我的」再塞回主办列表（已经挪到俱乐部栏）
